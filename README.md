Сайт-приглашение — это современный способ позвать гостей на свадьбу. Вместо бумажных открыток вы получаете красивую онлайн-страницу, где есть всё: дата, место, программа, карта проезда и форма для ответа.

**Посмотреть шаблоны:** (love-2026.ru)

## 🚀 Как заказать

1. **Выберите шаблон** — посмотрите демо и решите, какой стиль вам ближе
2. **Напишите нам** — в Telegram или по электронной почте
3. **Пришлите материалы** — ваши фото, имена, дату и место свадьбы
4. **Получите сайт** — через 1-2 дня вы получите готовый сайт со своим доменом
