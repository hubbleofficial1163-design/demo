# Свадебный сайт-приглашение

Готовый шаблон сайта для свадебного приглашения. Гости подтверждают присутствие через форму, все ответы собираются в Google Таблицу.

## Что внутри

- Адаптивный дизайн (работает на телефонах и компьютерах)
- Форма RSVP с проверкой заполнения
- Сбор ответов в Google Таблицу
- Галерея фотографий
- Карта проезда (Яндекс.Карты)
- Политика конфиденциальности (соответствует 152-ФЗ)

## Быстрый старт

1. Заменить фотографии в папке `images/`
2. Поменять имена и дату в `index.html`
3. Настроить отправку в Google Таблицу
4. Залить на GitHub Pages
